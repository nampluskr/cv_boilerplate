# D1 — PRD.md 적대적 교차 검증 기록

## 1. 검증 개요

`docs/dev/v0.1/PRD.md`에 대한 반대 벤더 적대적 검증 기록이다.

| 항목 | 내용 |
|---|---|
| 대상 문서 | `docs/dev/v0.1/PRD.md` |
| 작성자 | Claude Code (Opus 5) |
| 검토자 | Codex CLI, `gpt-5.6-sol`, `--sandbox read-only` |
| 검토자 허용 컨텍스트 | `PRD.md`, `BRIEF.md`, `AGENTS.md`, `CLAUDE.md` (읽기 전용) |
| 실행 일시 | 2026-08-18 |
| 실행 횟수 | 3회 (유효 1회) — Verification Attempt Limit 소진 |
| 결과 | Critical 0, Major 9, Minor 4 (합계 13) |

## 2. 실행 회차 기록

검증 한도 3회를 모두 사용했으므로 보완 후 재검증은 수행하지 않았다.

| 회차 | 실행 조건 | 결과 | 유효 여부 | 사유 |
|---|---|---|---|---|
| 1 | foreground 실행, 10분 시간 제한 | 시간 초과 종료, 출력 유실 | 무효 | 출력 버퍼링으로 산출물 확보 실패 |
| 2 | background 실행, 동일 프롬프트 | 검토 거부 | 무효 | 프롬프트가 셸 사용을 전면 금지하여 검토자가 파일을 읽을 수단이 없었음 |
| 3 | background 실행, 읽기 전용 셸 허용 프롬프트 | 검토 완료 | 유효 | 전체 지적 목록 반환 |

2회차 실패를 계기로 `AGENTS.md`와 `CLAUDE.md`의 Adversarial Review Rules에
"문서 검증 시 검토자의 읽기 전용 셸 사용 허용" 항목을 추가했다.

## 3. 지적 사항 및 처리

Critical 지적은 없다. Major 9건과 Minor 4건은 모두 유효한 지적으로 판단해 반영했다.

| 번호 | 심각도 | 지적 | 처리 | 반영 내용 |
|---|---|---|---|---|
| 1 | Major | 태스크별 확정 모델명이 요구사항에 없어 임의 모델 세트로도 AC 통과 가능 | 반영 | 2.1 확정 비교 모델 매트릭스 신설(비교 축 포함), `FR-18`·`FR-28`·`AC-02`가 이를 참조하도록 수정 |
| 2 | Major | `OUT-09`의 "v0.1 pretrained는 모두 torchvision에 존재" 근거가 YOLO(ultralytics)·anomalib 모델과 충돌 | 반영 | `OUT-09` 사유를 매트릭스 기준으로 교체, `CON-05`(비 torchvision 가중치 오프라인 로드) 신설, BRIEF 8.1과 4·8장의 불일치를 8장 미결정 사항으로 명시 |
| 3 | Major | 벤치마크의 일괄 "추론" 요구 누락 | 반영 | `FR-24`를 학습·평가·추론 순차 실행으로 확장, `AC-04`에 split별 추론 산출물 검증 추가 |
| 4 | Major | Detection 일반성이 수용 기준에서 검증되지 않음 | 반영 | `AC-09` 신설(N=0·N=1·N>1·복수 클래스 혼합 배치), `FR-15` 상세 보강, `NFR-06`을 MUST로 상향 |
| 5 | Major | train/valid/test 누수 방지 요구 없음 | 반영 | `FR-17`에 split 상호 배타성 추가, `NFR-03`에 valid 기반 모델 선택·test 최종 평가 전용 원칙 추가, `AC-10` 신설 |
| 6 | Major | `NFR-02` 판정 기준이 "기록됨"만 확인하여 실제 통제를 검증하지 못함 | 반영 | `FR-35`(통제 조건 기계적 검사, 위반 시 실행·leaderboard 생성 실패) 신설, `NFR-02` 판정 기준을 `FR-35` 통과로 변경 |
| 7 | Major | 재현성의 허용 오차와 seed 적용 범위 미정의 | 반영 | `NFR-01`에 seed 적용 범위 명시, 허용 오차와 deterministic 설정은 `SPEC.md` 확정 사항으로 8장에 등록 |
| 8 | Major | `NFR-05`(config만으로 확장)와 `NFR-06`(어댑터 필요)이 상호 모순 | 반영 | `NFR-05`를 모델 확장으로 한정, `NFR-06`을 데이터셋 교체성(어댑터 구현 + 엔진·Loss·Metric 무수정)으로 분리 |
| 9 | Major | Anomaly pixel-level의 필수 여부가 `FR-16`과 `FR-19` 사이에서 상충 | 반영 | `FR-16`에 "MVTec `bottle`은 mask 보유이므로 pixel-level 필수" 명시, `FR-19`를 "GT mask 보유 시 pixel-AUROC"로 조건화, `AC-06`에 두 metric 산출 검증 추가 |
| 10 | Minor | 일부 요구사항의 BRIEF 근거 절 번호 오류(`FR-05`, `FR-06`, `FR-17`, `CON-05`) | 반영 | 근거를 BRIEF 6 등으로 정정하고, 상위 문서에 없는 항목은 `AGENTS` 또는 `PRD` 표기로 구분 |
| 11 | Minor | NFR 표에 근거 열이 없어 원천 추적 불가 | 반영 | NFR 표에 근거 열 추가 |
| 12 | Minor | `FR-01`의 CLI override가 근거 없이 MUST로 승격됨 | 반영 | `FR-01`에서 분리해 `FR-34`(SHOULD, 근거 `PRD`)로 이동, CLI 문법은 `SPEC.md` 확정 사항으로 등록 |
| 13 | Minor | `NFR-12`의 "합리적 시간"이 측정 불가능 | 반영 | 태스크별 스모크 규격(샘플 수·epoch·최대 실행 시간)을 `SPEC.md`에서 수치로 정의하도록 변경 |

검토자가 무단 범위 변경이 아니라고 명시적으로 인정한 항목은 `OUT-10`~`OUT-13`이다.
통과 판정을 받은 축은 task-agnostic 엔진, target 규약, 오프라인, 평가 무결성, 문서 규칙이다.

## 4. 남은 위험

검증 한도 소진으로 보완 결과에 대한 재검증을 수행하지 못했다. 다음 위험이 남는다.

- 3회차 지적을 반영한 현재 `PRD.md`는 반대 벤더 재검토를 거치지 않았다. 새로 추가한 `FR-34`, `FR-35`,
  `CON-05`, `AC-09`, `AC-10`과 2.1 매트릭스는 검토자 확인 없이 작성자 판단으로 작성된 내용이다.
- `BRIEF.md` 8.1("v0.1 pretrained는 모두 torchvision에 존재")과 4·8장(YOLO, anomalib 모델)의 불일치는
  PRD 수준에서 해소할 수 없다. 사용자 확인 후 `BRIEF.md` 또는 조달 계획을 조정해야 한다.
- 재현성 허용 오차, 통제 필드 목록, 스모크 규격은 수치 없이 `SPEC.md`로 이월되었다. `SPEC.md`에서
  수치가 확정되기 전까지 `NFR-01`, `NFR-02`, `NFR-12`는 실제로는 판정 불가 상태다.
