## 미해결 잔여 위험 (Major/Minor 처리 후에도 남은 것)

1. `check_reproducibility.py`가 두 실행이 동일한 `config.resolved.yaml`/seed를 사용했는지 자체는 검증하지 않는다. 사용자가 실수로 다른 config를 비교해도 값만 맞으면 통과한다.
2. `--resume` 시 DataLoader shuffle generator의 진행 상태가 복원되지 않아, 재개 후 셔플 순서가 원래 연속 실행과 정확히 일치하지는 않는다(모델·옵티마이저·스케줄러·전역 RNG는 정확히 복원됨).
3. 오프라인 가드는 Python `socket` 모듈 레벨 패치이며 UDP 비연결 소켓의 `sendto`, 로컬 프록시를 경유하는 트래픽까지는 차단하지 않는다. 완전한 네트워크 격리가 필요하면 OS 레벨 샌드박스(예: 컨테이너 네트워크 격리)가 별도로 필요하다.
